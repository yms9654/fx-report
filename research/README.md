# 연구 노트 — 무엇이 랜덤워크를 이기는가

리포트에 새 모델을 넣기 전에 여기를 먼저 통과시킨다.
기준선을 못 이기면 넣지 않는다.

## 결과 (2004-04-12 ~ 2026-09-09, 5,556영업일, 워크포워드)

### 방향·수익률 예측 — 전부 실패

기준선: 랜덤워크(=0 예측). RMSE 비율 1.0 미만이어야 이긴 것.

| 모델 | 1일 | 1주 | 4주 | 4주 방향적중 |
|---|---|---|---|---|
| Ridge | 1.009 | 1.025 | 1.037 | 47.3% |
| GBM | 1.005 | 1.007 | 1.011 | 51.9% |
| MLP (64,32) | 1.513 | 1.174 | 1.148 | 52.3% |
| LSTM (48u, seq40) | 1.000 | 1.002 | 1.007 | 45.7% |

GBM/MLP 의 4주 방향 적중이 유의해 보였으나 **표본 중첩 착시**였다.
20일 예측을 매일 뽑으면 2,191개 같지만 독립 표본은 109개다.
중첩 제거 시 z = 2.17 → 0.67 로 사라졌다.

### 변동성 예측 — HAR-RV 성공, 딥러닝 실패

기준선: 직전 22일 실현변동성 그대로.

| 모델 | RMSE 비율 | 판정 |

| **HAR-RV** (log RV 2/5/22일 선형) | **0.893** | 이김 (DM t=12.84) |
